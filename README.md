# Die Abenteuer von Johanni und Glacier

Ein Side-Scroller für Tablet, Handy und PC: Johanni reitet auf dem Einhorn Glacier, sammelt Sterne, zaubert gegen Trolle und Drachen und besiegt am Ende den Drachenkönig.

**Spielen:** https://sternenreiter2026.github.io/Johanni/

## Installieren als App
- **Android (Chrome / Firefox):** Link öffnen → Menü → „App installieren“
- **iPhone / iPad (Safari):** Link öffnen → Teilen → „Zum Home-Bildschirm“

## Dateien
| Datei | Inhalt |
| --- | --- |
| `index.html` | das komplette Spiel (Code, Glacier, Icons und Schrift eingebettet) |
| `bg_*.png` | sonnige Landschaft, 4 Parallax-Ebenen |
| `gw_*.png` | Gewitter-Landschaft, 4 Parallax-Ebenen |
| `drachen.png` | Drachen, Drachenkönig und Feuerbälle |
| `trolle.png` | Trolle, Trollkönig und Felsbrocken |
| `manifest.webmanifest`, `sw.js`, `icon-*.png`, `apple-touch-icon.png` | App-Installation und Offline-Betrieb |
